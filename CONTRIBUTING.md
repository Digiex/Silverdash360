# Contributing to Silverdash360

Contributions and pull requests are welcome: fixes, features, documentation, testing on your console, and good bug reports.

- **Problems and feature requests** go to [GitHub Issues](https://github.com/Digiex/Silverdash360/issues). Look through the open ones first; the forms ask for what helps. See [Problems and ideas](https://digiex.github.io/Silverdash360/issues/).
- **For a new feature or a bigger change**, open an issue first, or comment on one, so we can agree on how it should work. A small fix can go straight to a pull request.
- **Pull requests** go against `master`, one change each. Say what it changes and why, which issue it fixes, and how you tested it: on a console or in xenia, and which test suites passed. Update the docs in `docs` when what users see changes.
- **Building and testing**: see [Development](https://digiex.github.io/Silverdash360/development/) and [tests/README.md](tests/README.md). You need the [Silverlight360](https://github.com/Digiex/Silverlight360) SDK and a runtime you made yourself.
- **What can't go in**: the runtime or the donor app's files (`default.xex`, `xcoreclr.dll`, the framework assemblies), Xbox 360 SDK code, files from a console's firmware, and anything else whose license doesn't allow it.
- **License**: by opening a pull request, you agree that your contribution is licensed under Silverdash360's [license](LICENSE.md), the PolyForm Noncommercial License 1.0.0 with its additional condition.

The full guide is [Contributing](https://digiex.github.io/Silverdash360/contributing/) in the docs. Questions are welcome on the [Silverdash360 thread on Digiex](https://digiex.net/threads/silverdash360-homebrew-xbox-360-dashboard.20103/).
