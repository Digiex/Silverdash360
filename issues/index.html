Problems and ideas¶

Problems and feature requests go to GitHub Issues, where they're kept track of until they're fixed or done. You need a GitHub account, which is free. For questions and talk about Silverdash360, there's the Silverdash360 thread on Digiex.

Before you open one, look through the open issues in case it's there already. A 👍 on an issue says you'd like it too, and a comment can add what's different for you.

Reporting a problem¶

See Troubleshooting first. If it's not there, report the problem. The form asks for:

  • What happened, and what you expected instead.
  • How to make it happen: the section, page or title, and the buttons you pressed.
  • The version: Version in settings, such as 0.1.2, build 77 (commit 3c4fe74). Updating to the latest version first is worth it, in case it's fixed already.
  • The console: System version in settings.
  • The log, if you can: Data\Logs\silverdash.log.last in Silverdash360's folder, from the run that went wrong, or silverdash.log while it's still running. Copy it off with the FTP server and drag it into the form. It has your gamertag and the names of your games and apps in it.

A screenshot or a photo of the screen helps too.

Asking for a feature¶

Request a feature: what you'd like Silverdash360 to do, and what it would help you with. How the Xbox Dashboard or another dashboard does it is useful to know.

To fix or make it yourself, see Contributing: pull requests are welcome.
